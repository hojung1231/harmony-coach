# 🎤 화음 코치 (Harmony Coach)

악보로 만든 **화음음과 가사만** 듣고 부르면서, 내 음이 맞는지 **화면 색**으로 바로 확인하는 간단한 화음 연습 앱이에요.

- 올려야 하면 **▲ + 반투명 빨간색**
- 내려야 하면 **▼ + 반투명 파란색**
- 맞으면 **✓ + 초록색** (허용 오차: 넉넉하게 ±70 / 보통 ±50 / 정확하게 ±30 센트)

## 설치
- **안드로이드 앱(APK):** https://github.com/hojung1231/harmony-coach/releases/download/android/harmony-coach.apk
- **웹앱:** https://hojung1231.github.io/harmony-coach/ → 브라우저 메뉴에서 "홈 화면에 추가"

## 새 곡 추가 (원곡 MP3 + 악보만)
홈의 **+** → **원곡 MP3** 고르기 → **악보**(PDF 또는 사진 여러 장) 고르기 → **곡 만들기**.
1. **Claude(AI)가 악보를 읽어** 노래 멜로디의 음높이·박자·가사 음절로 바꿔요 (도돌이표·D.S.·코다는 부르는 순서대로 펼침). 보통 1~3분.
2. 앱이 그 음표로 **화음(3도 위/3도 아래/6도 아래)**과 마디·악보 표시를 만들어요.
3. 원곡 MP3의 음 흐름을 분석해 **템포 차이와 노래 시작 위치, 간주 길이 차이를 자동으로 맞춰요** (악보 템포 ±12% 안).
4. **가사**는 MP3 안의 가사(멜론·지니 MP3)를 쓰고, 없으면 악보의 가사를 써요.

악보 읽는 방법은 두 가지 중에 골라요:
- **Claude 앱으로 (구독, 추가 요금 없음)**: ① 지시문 복사 → ② Claude 앱에서 새 대화에 악보 PDF·사진을 올리고 지시문 붙여넣어 보내기 → ③ Claude 답의 코드 블록 복사 → 앱에서 'Claude 답 붙여넣기'. 붙여넣으면 마디·음표 수를 바로 확인해 줘요. 고른 MP3와 붙여넣은 답은 앱을 오갈 때 지워지지 않게 저장돼요.
- **API 키로 (자동)**: 악보 파일만 고르면 앱이 직접 Claude API를 불러요.

API 키 방법에 필요한 것: **Claude API 키** (console.anthropic.com 에서 발급, 처음 한 번 입력 · 설정에서 바꾸기). 키와 곡은 폰에만 저장되고, 악보는 Claude API 로만 보내요. 곡 하나에 보통 500~1,500원 정도 API 요금이 들어요 (모델 `claude-opus-5-5`).
잘못 만들어진 곡은 홈 목록의 **삭제** 버튼으로 지워요.

## 사용법
1. 곡을 고르면, 처음 한 번 가사를 붙여넣어요(가사는 저작권 때문에 앱에 넣지 않고 폰에만 저장해요).
2. ▶ 를 누르면 화음음이 나오고 가사가 지나가요. 화음음을 따라 부르면 화면 색이 바뀌어요.
3. 화음 종류(3도 위 / 3도 아래 / 6도 아래), 속도(1 / 0.8 / 0.6 / 0.5배), 🎵 멜로디음은 연습 화면 아래에서 바꿔요.
   화음음·멜로디음은 앱이 직접 만드는 소리라 느리게 해도 음정이 그대로예요.
4. **원곡과 함께:** 연습 화면의 '원곡+'로 폰에 있는 원곡 음원을 한 번 연결하면, 1배속에서 원곡이 나오고 악보·가사·화음이 원곡 박자(악보-녹음 정렬)에 맞춰 진행돼요. 다른 속도에선 자동으로 꺼져요.
5. **스피커로 연습할 때:** 설정의 '스피커 소리 걸러내기'(기본 켬) — 마이크 에코 제거, 멜로디음은 판정에서 제외, 시작 카운트 때 스피커 소리 크기를 재서 그보다 큰 소리(내 목소리)만 판정해요. 화음음은 계속 나와요. 이어폰이면 꺼도 돼요.
6. **음량:** 화음음·멜로디음·원곡 버튼을 누른 채 위로 끌면 커지고 아래로 끌면 작아져요(0~100). 한 번 누르면 켜기/끄기.
7. **가사:** 복사할 때 딸려 온 제목·가수·작사/작곡 줄은 자동으로 빠져요. 연습 화면의 '가사' 버튼으로 다시 넣을 수 있어요.

## 화면 모드 (연습 화면 위 버튼으로 전환)
- **화살표 모드:** ▲/▼/✓ + 배경색 + 오선 악보
- **그래프 모드:** 화음 음(파란 막대, 연한 띠 = 허용 오차)이 흘러가고, 그 위에 내 목소리가 실시간 선으로 그려져요. 맞으면 초록, 높으면 파랑, 낮으면 빨강.

## 화음 가이드음 음색
연습 화면 위 **음색** 버튼에서 고르고, 재생 중에 바로 비교할 수 있어요.
- **피아노**(기본): 톡 치고 줄어듦 — 음이 바뀌는 순간이 또렷
- **벨**: 한 옥타브 위에서 울림 — 목소리 위로 가장 잘 빠져나옴
- **마림바**: 짧게 톡 — 내 목소리를 가장 덜 가림
- **오르간 / 휘슬**: 끝까지 이어지는 소리 — 긴 음 맞추기 좋음
- **신스(기존)**, 그리고 **한 옥타브 위로** 옵션

## 음원·가사 구하기 (멜론·지니)
멜론·지니는 외부 앱이 음원·가사를 가져갈 공개 API가 없어 자동 내려받기는 지원하지 않아요. 대신:
- **가사 화면**: 곡 제목이 들어간 멜론/지니 검색 링크 → 가사 복사 → '복사한 가사 붙여넣기' 한 번
- **원곡+**: 멜론/지니 검색 링크에서 MP3 다운로드(구매) → '폰에서 MP3 고르기'

## 유튜브 영상을 원곡으로 (실험)
'원곡+' 창에서 유튜브 링크를 붙여넣어 연결하면, 영상이 연습 화면에 보이고 가사·화음·판정이 영상 재생 시간을 따라가요.
영상마다 노래 시작 시점이 달라 '첫 가사에 맞추기'(가수가 첫 가사를 시작하는 순간 누름)와 당기기/늦추기(0.1초)로 맞춰요.
유튜브 공식 IFrame Player API를 쓰며, 영상은 항상 화면에 보이는 상태로만 재생해요. 퍼가기가 막힌 영상은 재생되지 않아요.

## 이동
- **재생 바**를 누르거나 끌면 그 위치로 이동
- **◀ 마디 / ▶ 마디**: 이전·다음 마디로 (마디 중간이면 그 마디 처음으로)
- **반주 넘기기**: 전주·간주를 건너뛰어 다음 노래 시작 2초 전으로 (반주 구간에서는 버튼이 노랗게 표시)
- **소리·화면 싱크**(설정): 블루투스 이어폰의 소리 지연을 자동 감지해 화면·판정을 늦추고, 직접 미세 조절도 가능

## 기본곡
- **숙녀에게 (변진섭)**: 악보 멜로디를 원곡 녹음에 맞춰 시간 정렬한 데이터(`songs/sooknyeo.json`). 가사는 들어 있지 않아요.

## 곡 파일 형식 (`.json`, 고급 — 새 곡 추가 화면 맨 아래 '곡 파일이 이미 있다면')
```json
{
  "format": "harmony-coach-song", "version": 1,
  "title": "곡 제목", "artist": "가수", "key": "D 장조",
  "notes": [[시작초, 길이초, MIDI음, 가사음절 또는 1/0], ...],
  "harmony": { "third_up": [MIDI, ...], "third_down": [...], "sixth_down": [...] }
}
```
`notes` 의 네 번째 값이 가사 음절이 시작하는 음이면 1(또는 음절 글자), 앞 음절을 끄는 음이면 0이에요.

## 업데이트
앱을 켤 때 새 버전이 있으면 홈에 **업데이트** 버튼이 떠요. 설정의 **업데이트 확인**으로도 확인할 수 있어요.
배포할 때는 `version.json`, `js/update.js`의 `APP_VERSION`, `sw.js`의 `CACHE` 숫자를 같이 올리고 `main`과 `gh-pages`에 push 해요.
