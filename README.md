# 🎤 화음 코치 (Harmony Coach)

노래를 넣으면 **원곡 보컬 멜로디를 자동으로 따고**, 가요에서 흔히 쓰는 방식으로 **화음 라인**을 만들어 줍니다.
연습할 때는 **목표 화음 그래프 위에 내 목소리가 실시간으로 그려져서** 잘 따라가고 있는지 바로 보여요.

## 기능
- **노래 추가**: 폰의 음원 파일(mp3/m4a/wav/mp4) 선택, 또는 다른 기기에서 튼 노래(유튜브 프리미엄 등)를 마이크로 녹음
- **멜로디 자동 추출**: 스테레오 중앙(보컬) 강조 + 하모닉 분석으로 보컬 음높이 추적 → 음표로 정리, 조(Key) 자동 추정
- **화음 종류**: 3도 위(가장 흔함) / 3도 아래 / 6도 아래 / 5도 위 / 4도 아래 / 옥타브 — 조에 맞는 음계(다이어토닉)로 계산
- **멜로디 수정**: 그래프에서 잘못 따진 음을 눌러 반음·옥타브 조정 또는 삭제
- **실시간 연습 (그래프)**: 파란 띠 = 목표 화음, 내 목소리 선 = 초록(정확)/노랑(조금 벗어남)/빨강(많이 벗어남)
  - 속도 0.5x~1.0x, 원곡 소리 끄기, 멜로디음/화음 가이드음 켜기, 구간 반복
- **리뷰**: 점수, 구간별 결과, 음마다 "높게/낮게/흔들림/안 부름"과 센트 오차 → 원하는 구간만 다시 연습
- **원곡 없이 한 음씩 연습**: 기준음을 듣고 초록 띠 안에서 0.6초 버티면 다음 음으로 (멜로디 같이 울리기 옵션)
- 모든 데이터는 폰 안(IndexedDB)에만 저장, 오프라인 동작

## 폰에 설치하기
1. GitHub Pages 주소(`https://<아이디>.github.io/harmony-coach/`)를 폰 브라우저로 엽니다.
2. **Android(Chrome)**: 메뉴 ⋮ → "홈 화면에 추가"/"앱 설치"
   **iPhone(Safari)**: 공유 버튼 → "홈 화면에 추가"
3. 홈 화면 아이콘으로 실행하면 일반 앱처럼 전체 화면으로 열려요.

## 사용 팁
- 🎧 **이어폰 필수** — 스피커로 들으면 마이크가 원곡 목소리를 함께 잡습니다.
- 블루투스 이어폰은 지연이 있으니 설정에서 "지연 보정"을 200~300ms로 올리세요.
- 남녀 음역이 다르면 "화음 옥타브"를 조정하거나 설정의 "옥타브 무시"를 켜두세요(기본 켜짐).
- 반주가 큰 곡은 멜로디 추출이 틀릴 수 있어요. 미리듣기의 "멜로디음"으로 확인하고 고쳐주세요.

## 유튜브 프리미엄에 대해
유튜브 음원은 DRM으로 보호되어 있고 공식적으로 오디오를 가져올 방법(API)이 없어, 앱이 직접 불러올 수 없습니다.
대신 **다른 기기에서 유튜브로 틀고 이 앱으로 녹음**하는 방식을 지원합니다(개인 연습용).

## 개발
빌드 과정 없는 순수 HTML/JS입니다. 로컬 실행: `python3 -m http.server` 후 `http://localhost:8000`.
`main`에 push하면 `.github/workflows/pages.yml`이 GitHub Pages로 자동 배포합니다.
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정)
